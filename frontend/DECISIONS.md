# Решения по frontend

## Продуктовый объём первого прохода

- Главный демонстрационный сценарий: загрузить запись, увидеть этапы локальной обработки, открыть итоговый протокол, проверить саммари, поручения и диаризованный транскрипт, затем экспортировать результат.
- Основной интерфейс на русском языке. Казахский и смешанная речь отображаются в транскрипте и настройках распознавания.
- Предоставленные протоколы используются как обезличенные демонстрационные данные.

## Интеграция

- Backend в репозитории отсутствовал, поэтому временные данные находятся только в `features/meetings/api.ts` и включаются через `NEXT_PUBLIC_USE_MOCKS=true`.
- При готовом API интерфейс переключается на REST без переписывания страниц и компонентов: достаточно установить `NEXT_PUBLIC_USE_MOCKS=false`.
- Базовый REST URL: `http://localhost:4000/api/v1`.

## Безопасность

- Интерфейс не обращается к внешним AI API.
- Формулировки в UI поддерживают on-premise модель обработки; реальную изоляцию данных должен обеспечить backend и инфраструктура.
