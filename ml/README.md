# ML

Зона ML-команды: полностью локальная обработка записей совещаний.

## Ответственность

- speech-to-text для русского, казахского и смешанной речи;
- диаризация и сопоставление реплик со спикерами;
- формирование краткого саммари;
- извлечение поручений: содержание, ответственный, срок и приоритет;
- оценка уверенности и метаданные обработки.

## Интеграционная граница

ML-сервис вызывается только backend-компонентом. Frontend не должен знать адрес ML-сервиса или формат внутренних ML-заданий.

Развёртывание должно поддерживать закрытый контур и не зависеть от внешних облачных AI API. Модели, веса, датасеты и виртуальные окружения должны храниться и игнорироваться локально внутри `ml`.

Реализация ML в текущий frontend-проход не добавлялась.
