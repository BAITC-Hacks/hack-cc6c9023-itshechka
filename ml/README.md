# ML service

Здесь размещается локальный ML-пайплайн: speech-to-text для RU/KZ/mixed, диаризация, саммари и извлечение поручений.

ML-компонент не входит в pnpm workspace и предоставляет внутренний API только для `apps/api`. Frontend не должен обращаться к ML-сервису напрямую. Веса моделей, датасеты и виртуальное окружение не коммитятся.
