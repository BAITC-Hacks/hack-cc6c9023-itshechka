# Данные: что есть и чего не хватает

Предоставлено: два MP3, два DOCX с диалогами и авторскими таблицами задач, описание кейса. Продолжительность MP3 по метаданным: 274.25 с и 206.03 с, суммарно 8.00 мин; звук 48 кГц. В MP3 также есть картинка-обложка: это не видеозапись встречи. Прослушивание и сопоставление всех слов с аудио в текущую проверку не входило.

Импорт: `python ml.py prepare-data --source ..`. Скрипт сохраняет оригиналы под ASCII-именами, отделяет реплики от итоговых таблиц, создаёт JSON и контрольные суммы. Не используйте эталонные задачи или саммари как часть входного промпта.

`data/synthetic` содержит только шаблонные текстовые данные. Это не звуковая синтетика. Поддержка kk/mixed проверяется здесь только как обработка Unicode и шаблонная классификация, не как качество восприятия речи.

## Следующий полезный сбор

Запишите по 2–3 минуты вымышленных совещаний в трёх режимах: ru, kk, mixed. Желательно 3 разных человека, обычный ноутбук/телефон, отдельная запись на каждый режим. Уведомите участников. Чистое TTS-аудио не заменяет проверку реальных голосов, акцентов, шума и перебиваний.

Сценарии для записи:

1. Явное поручение: «Айдана, подготовьте отчёт к 15 октября» / «Айдана, есепті 15 қазанға дейін дайындаңыз».
2. Изменённый срок: исполнитель не успевает, председатель явно соглашается на новый срок.
3. Два поручения одному человеку, одно без срока.
4. Исполнитель — отсутствующий юрист, а поручение озвучивает руководитель.
5. Уже выполненная задача, неподтверждённая идея и отклонённое предложение — отрицательные примеры.
6. Повтор всех поручений в конце, который не должен удвоить список.
7. Смена языка внутри одной реплики: «Марат, есеп дайын болсын, дедлайн — пятница»; носитель языка проверяет естественность.

Для каждой записи сохраните:

```json
{
  "meeting_id": "mixed_unseen_01",
  "meeting_date": "подтверждённая дата ISO",
  "language": "mixed",
  "audio_file": "mixed_unseen_01.wav",
  "consent": true,
  "annotation_status": "human_checked",
  "segments": [{"start": 0.0, "end": 2.0, "speaker": "P1", "text": "точная расшифровка"}],
  "tasks": [{"id": "a01", "task": "результат", "owner": "исполнитель", "deadline_text": null}]
}
```

Это **шаблон**, числа и текст нельзя использовать как настоящую разметку. Размечайте начало/конец по аудио, включая перебивания. Сохраните словесные самопоправки в ASR-эталоне, а финальную согласованную задачу — в task-эталоне.

Разделяйте train/dev/test целыми встречами и по возможности участниками. Не режьте одну встречу на train/test-фрагменты. Независимый тест не включайте в примеры промпта и не используйте для выбора порога.

Почему в комплекте нет скачивания большого внешнего датасета: первому MVP полезнее локальные готовые веса и несколько размеченных предметных записей. Публичный корпус отдельных фраз сам по себе не размечает поручения и диаризацию встреч; его добавление потребует отдельной проверки лицензии, домена и языков. Генератор и готовые текстовые сплиты уже включены.
